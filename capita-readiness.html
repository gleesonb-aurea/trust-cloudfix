Additional Context: ITSM Integration

Capita's request specifically references a CloudFix + ServiceNow integration. For clarity on how CloudFix integrates with ITSM and service desk platforms:

  • CloudFix uses a webhook-based integration pattern. When a cost optimisation opportunity is identified, CloudFix fires an HTTPS POST to an inbound handler URL in the customer's ITSM platform (ServiceNow, Jira Service Management, or any webhook-capable service desk).
  • The ITSM platform manages the approval workflow internally. Once approved, it fires an HTTPS POST back to the CloudFix API with an approval signal and Bearer token authentication.
  • No CloudFix software is deployed inside the ITSM platform, and no ITSM credentials or data are stored by CloudFix. The integration is outbound-first and requires only that Capita whitelist the CloudFix API endpoint for the approval callback.
  • See the Architecture page for the full integration diagram and the Data Processing page for a table of exactly what data crosses each boundary.
